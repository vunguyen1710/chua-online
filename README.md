# Xả Stress Online 6.9 — Phao Vịt 3D và camera gần

- Thay mô hình phao vịt cũ bằng GLB mới: một vòng phao liên tục với chỗ ngồi, thân/đầu/cánh/đuôi/mỏ/mắt có hình khối hoàn chỉnh.
- Sửa lỗi phao dự phòng không được thay thế khi file GLB tải thành công.
- Nhân vật ngồi tựa nhẹ trên phao vịt, thay cho tư thế nằm ngang xoay 90 độ dễ bị lệch.
- Camera trôi sông đặt gần hơn, có thể vuốt để xoay và dùng bánh xe chuột để zoom.
- Giữ lại map sông, mặt nước, Multiplayer và các khu xả stress khác.

Chạy: `npm install` rồi `npm start`. Sau khi upload đầy đủ project lên GitHub, redeploy Render. Kiểm tra nhãn **v6.9**.
